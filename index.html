It works just like decimal — but doubling instead of ×10

You already know place-value columns from normal numbers: units, tens, hundreds. Each column is worth 10× more. Binary is the same idea, but each column is worth 2× more: units, twos, fours, eights…

Hexadecimal — binary's shorthand

Binary is long to write: 11111111 is a lot of typing for 255! Programmers use hexadecimal (hex): counting with 16 symbols — 0–9 then A B C D E F. One hex digit replaces exactly 4 bits.

The lookup table — 0 to 15

💡 Programmers put a tag in front of a number to say which system it's in: 0x means hex (like 0xFF = 255) and 0b means binary (like 0b1111 = 15). Without a tag, 10 is confusing — is it ten, 0b10 (two), or 0x10 (sixteen)? The tag tells you! You've seen hex before, by the way: colour codes like #FF8800 are three hex bytes — red, green, blue.

ASCII — how letters become numbers

Computers can only store numbers. So long ago, everyone agreed on a code: A = 65, B = 66, C = 67… and small letters a = 97 onwards. That agreement is called ASCII. Every letter is one byte.

Type something — watch it turn into bytes

🎉 You found a secret! That character is not in ASCII — it's Unicode.

ASCII (from 1963!) only has 128 characters — just enough for English. But the world needed accents, Chinese, Arabic, emoji… so Unicode was invented: one giant numbered list with a number for every character in every language — more than 150,000 so far. A character's number is called its code point and is written in hex, like U+1F600 for 😀.

And the bytes? UTF-8 is the recipe that turns a code point into bytes: ASCII characters still take exactly 1 byte (their old codes!), European accents take 2, and emoji take 4 bytes. So remember: Unicode gives the number, UTF-8 stores the number as bytes — and every ASCII message is already valid UTF-8. That clever trick is why the whole internet uses it.

Show the full ASCII letter table
🔎 Spot the pattern: capital A is 01000001 and small a is 01100001. Only one bit is different (the 32s column)! That single bit is the difference between BIG and small letters.

⚡ How the lock works — XOR

The lock uses an operation called XOR (say "ex-or"). It compares two bits and asks one question: are they different?

message bit0011
key bit0101
result0110

Try it — flip any switch and watch the bottom row light up exactly where the two rows above disagree:

message byte
key byte
locked byte = message ⊕ key

The magic: XOR with the same key twice brings the message back. Lock it: message ⊕ key. Unlock it: locked ⊕ key = message again. That's why you and your friend just need the same key.

🎖️ The unbreakable code: if your key is random, as long as the message, and never used twice, this becomes a one-time pad — the only cipher in the world that's mathematically impossible to crack. Real spies carried little pads of random keys and burned each page after one use!
